PAM main window — 3 mockups

PAM is the display + audio profile app (TASK-1). Each option below is the same app window with your real screens and audio devices; only the layout differs. Everything works: pick a profile, drag screens (they snap), change audio, add or remove screens. The projector is shown as not connected to illustrate remembered screens (it is connected right now). Changes are shared between the three options.

1. Main window layout

What it's for: where profiles, the screen arrangement, audio and shortcuts live. What differs: how the window is organized.
